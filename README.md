# AI Interview

`AI Interview` 是一个基于 `Go + Vue 3` 的 AI 模拟面试工具。

当前仓库先落地两部分：

- `frontend`：Vue 3 页面骨架
- `database`：核心数据表设计

后续推荐扩展：

- `backend`：Go API 服务
- `deploy`：部署与环境配置

## 目录结构

```text
AI_Interview/
├─ frontend/
│  ├─ src/
│  │  ├─ assets/
│  │  ├─ components/
│  │  ├─ data/
│  │  ├─ router/
│  │  └─ views/
├─ database/
│  ├─ README.md
│  └─ schema.sql
└─ backend/
   └─ README.md
```
